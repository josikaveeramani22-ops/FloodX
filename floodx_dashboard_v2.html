ℹ️ ABOUT

FloodX 2.0 — real-time urban flood nowcasting & safer-route guidance.

• Tech: Python · FastAPI · Pydantic · Uvicorn · SQLite · SSE / WebSocket · HTML5/CSS3/JS · Leaflet + OpenStreetMap.
• Flow: sensors → POST /ingest → validate → SQLite → broadcast → dashboards update live.
• SoS: water level (cm), flow (L/s ×10 = L/min shown), rainfall (mm/hr), drain saturation %, CCTV.
• Data: synthetic 2,000-row CSV (8 zones/streets) for demo; same pipeline accepts real ESP32 sensor JSON.
• Interfaces: this admin view (city-wide) and the resident view (/user) with safer-route planning.
